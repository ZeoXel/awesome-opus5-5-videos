# 《从"我"出发，找家人》动效教学视频 · 剧本

> 对象：幼升小（5–6 岁）　|　用途：课堂教学，教师可随时暂停　|　时长：约 5 分钟，分 6 幕
> 参考：附图《我的家庭图谱》（爸爸这边 / 妈妈这边两页），以及本仓库案例的写法：
> `howdevelop-733090`（逐秒分镜 + 屏幕文字 + 准确性约束）、`astrothewizard-618782`（教育片：角色有性格、模拟真实过程、笑点和回扣、烧录字幕、自己审片）、`wani-shola-459278`（Remotion，一个镜头只讲一件事，转场不硬切）、`verbove-268381`（同一个元素变形贯穿全片，先出联系表再渲染）。

---

## 一、制作规格

- 1920×1080，30 fps，总长约 5:00；6 幕各自是一个 Remotion `<Sequence>`，也能单独导出成短片，方便老师分课时播放。
- **用 Remotion 制作**：每个人物、每条连线都是 React 组件，用 `useCurrentFrame()` 驱动；家庭关系写在一份数据文件里（`family.ts`），以后做"爷爷奶奶的兄弟姐妹"等续集，只改数据、不重画。
- 字体：霞鹜文楷（楷体，与小学课本字形一致，开源 OFL 授权）；拼音带声调，写在汉字上方。
- 关掉声音也要能看懂：所有旁白都烧录成字幕；关键字用颜色区分（**堂 = 橙色**，**表 = 青色**）。
- 每个"停一停"卡片都在视频里留出 5 秒倒计时，老师也可以在这里按暂停让孩子抢答。
- 交付：MP4 成片、6 段分幕 MP4、Remotion 工程源码、教师讲稿（带时间码）。

## 二、核心视觉想法（全片只用这一个）

**称谓 = 走一条路 + 比一比。**

画面上只有一棵从"我"长出来的家庭树。每认识一个亲戚，就从"我"出发**沿连线走一遍**：
- 走的路经过**爸爸的兄弟**（伯伯、叔叔）→ 这条线亮成**橙色**，前缀是"堂"；
- 走的路经过**其他人**（姑姑、舅舅、姨妈）→ 这条线亮成**青色**，前缀是"表"；
- 到了孩子身边，两个小人背靠背**比身高**：比我大 → 哥 / 姐，比我小 → 弟 / 妹。

两个字拼在一起就是称谓。每个转场都是在"走路"或"比身高"，不用一张张换 PPT。

## 三、美术与角色

- 整体：暖米色纸面（#FBF7F0），浅棕连线（#B89B7A），深褐文字（#2B2622），和附图一致的绘本风。
- 人物是圆润的扁平插画，每人一张米色"相片卡"，下面写名字和一行小字（如"爸爸的弟弟"）。服装颜色沿用附图：

|---|---|---|

| 奶奶 | 灰色卷发、粉色开衫 | 爸爸的妈妈 |
| 伯伯 | 棕色毛衣，比爸爸高一点 | 爸爸的哥哥 |
| 爸爸 | 绿色毛衣 | 我的爸爸 |
| 叔叔 | 牛仔衬衫，比爸爸年轻 | 爸爸的弟弟 |
| 姑姑 | 短发、紫色开衫 | 爸爸的姐妹 |
| 外公 | 灰发、绿色中式上衣 | 妈妈的爸爸 |
| 外婆 | 灰色短卷发、浅蓝开衫 | 妈妈的妈妈 |
| 妈妈 | 棕色长发、米白毛衣 | 我的妈妈 |
| 舅舅 | 浅灰毛衣 | 妈妈的兄弟 |

| 表弟 | 背带裤，比我矮 | 比我小 |

- "我"有性格：好奇、爱抢答、偶尔说错（第 2 幕的"说错了"是全片笑点，也是易错点）。
- 人物会眨眼、轻轻呼吸；出场时从卡片里"弹"出来，带一点回弹。
- 字卡学自附图下半部分：拼音在上、汉字在下、下面一条细线，"堂/表"用橙/青色。

## 五、准确性约束（制作时必须遵守）

- 伯伯 = 爸爸的哥哥，叔叔 = 爸爸的弟弟，姑姑 = 爸爸的姐姐或妹妹；舅舅 = 妈妈的兄弟，姨妈 = 妈妈的姐妹。
- **"堂"只用于爸爸的兄弟（伯伯、叔叔）的孩子**；姑姑、舅舅、姨妈的孩子都是"表"。
- 规则用**"走哪条路"**来讲，不用"跟我一个姓"来讲：有的孩子随妈妈姓，用姓氏判断会把他们弄糊涂。
- 哥/姐/弟/妹只看**比我大还是小**和**男孩还是女孩**，画面里用身高表示大小，字幕里说"比我大/比我小"（不说"比我高"），避免孩子以为看身高就能定称谓。
- 外公/外婆、姨妈在不少地方叫姥爷/姥姥、姨/阿姨；视频用附图的叫法，教师讲稿里提示老师可以替换成本地叫法。
- 拼音按附图标注：堂哥 táng gē、表妹 biǎo mèi、表姐 biǎo jiě、表弟 biǎo dì；单字卡标本调。

## 六、课堂使用建议（20 分钟一课时）

1. 导入（2 分钟）：问"过年你见到了谁？"，不播视频。
2. 播放第 0–2 幕（约 2 分钟），在"停一停①"暂停，请孩子用手指在屏幕上"走路线"。
3. 播放第 3 幕，在"停一停②"暂停抢答。
4. 播放第 4 幕，全班跟着拍手唱儿歌，可以重复播放这一段。
5. 播放第 5 幕闯关，分组比赛。
6. 第 6 幕后布置回家任务：发家庭树贴纸单。

## 七、制作与审片流程（沿用仓库案例的做法）

1. 先用 Remotion 搭好人物组件和 `family.ts`，渲染每个镜头的关键帧拼成**联系表**，逐张检查：字有没有挤、线有没有穿过人物、颜色是否正确。
2. 检查无误再渲染完整视频；转场处逐帧检查。
3. 配乐和音效用代码合成（音乐盒、木琴、拍手），音效时间直接取自剧本里的时间点，保证与画面同步；旁白出现时音乐自动压低，最后统一响度。
4. 旁白：本环境连不上在线语音合成服务，成片先用字幕；工程里附一个配音脚本，在能联网的电脑上运行即可按时间码生成旁白并混音。也可以由老师现场照讲稿讲。
