# 《豆豆拜年记》动效视频 · 剧本（第二版）

> 对象：幼升小（5–6 岁）　|　3 集，每集约 3 分钟，对应 [`教案.md`](教案.md) 的 2 课时
> 参考：附图《我的家庭图谱》，以及本仓库案例：`astrothewizard-618782`（角色有性格、视觉笑点、前后呼应）、`howdevelop-733090`（逐段分镜 + 准确性约束）、`wani-shola-459278`（Remotion，一个镜头只讲一件事）。
> 第一版（家庭关系图讲解版）保留在 git 历史中。

## 一、这一版改了什么

第一版像一节讲规则的课：旁白在讲，画面是关系图，孩子只能看。第二版是一个**故事 + 游戏**：

1. **有主角、有任务**：豆豆过年去拜年，可他老叫错人，请电视机前的小朋友当"小帮手"。
2. **有收集**：每叫对一位亲戚，就有一张贴纸飞进"全家福相册"。相册贴满的样子，就是参考图的两页。
3. **规则变成看得见的东西**：爸爸、伯伯、叔叔是**兄弟足球队**，穿橙色球衣，背后印着 1、2、3 号（号码就是大小）。小队员（他们的孩子）也穿橙色球衣，叫"**堂**"；别人家的孩子穿青色衣服，叫"**表**"。
4. **叫错有笑点**：叔叔被叫成"爷爷"，一下子长出白胡子、拄上拐杖："我有那么老吗？"笑点正好就是知识点。
5. **每 30 秒互动一次**：画面停顿 2–3 秒让孩子喊；豆豆做动作，孩子跟着做（见教案"魔法口令"）。
6. **用儿歌收尾**：《两只老虎》调，孩子都会唱。

## 三、美术

- 绘本风，暖色。人物比第一版大 2–3 倍，一个画面最多 4 个人。
- 场景：豆豆家（贴福字）→ 爷爷家门口（春联、灯笼、门框上的身高刻度）→ 爷爷家院子（足球门）→ 车窗外风景 → 外婆家客厅（象棋桌、糖果盒）→ 照相馆。
- 两个道具贯穿全片：
  - **全家福相册**：在右上角，每叫对一个人，就飞进去一张贴纸；
  - **身高门框**：比大小时，两人背靠背站到门框前，刻度上画一道线。
- 字卡学自附图：拼音在上、汉字在下；"堂"用橙色加一个小球衣图标，"表"用青色加一个小外套图标。

## 五、准确性约束

- 伯伯 = 爸爸的哥哥，叔叔 = 爸爸的弟弟，姑姑 = 爸爸的姐妹；舅舅 = 妈妈的兄弟，姨妈 = 妈妈的姐妹。
- **"堂"只用于伯伯、叔叔的孩子**；姑姑、舅舅、姨妈的孩子都是"表"。兄弟足球队是记忆用的比喻，片中只有爸爸和他的兄弟穿队服，规则不会出错。
- 不用"跟我一个姓"来讲。
- 哥姐弟妹看"比我大 / 比我小"。门框量身高只是演示，台词里一律说"比我大 / 比我小"。表妹踮脚的笑点正好说明：不能只看谁站得高。
- 叫错的笑点每集最多两个，叫错之后马上纠正，纠正时画面停留更久，避免孩子记住错误的叫法。
- 拼音：堂哥 táng gē、表妹 biǎo mèi、表姐 biǎo jiě、表弟 biǎo dì。

## 六、制作说明（Remotion，沿用第一版工程）

- 继续用"时间轴是唯一的数据源"的结构：每句台词、每个笑点、每个互动停顿、每个音效都写在 `timeline.json` 里，画面和声音都读它。
- 第一版的人物组件、比身高面板、字卡、倒计时、字幕、配乐系统都继续用。需要新增：
  - 场景背景：门、院子、车、客厅、照相馆；
  - 球衣（带号码）、相机、饺子、兔子、糖果等道具；
  - 角色动作：跑、踩滑板、举高高、踮脚、"嘭"一下变老；
  - 气泡字幕，以及每个角色不同音高的"叽里咕噜"拟声；
  - 贴纸飞进相册的动画；
  - 《两只老虎》调的儿歌编曲（这首是传统曲调）。
- 每集单独一个 Composition，导出 3 个 MP4；集内的互动停顿用"⏸"标出来，老师可以在这里多停一会儿。
