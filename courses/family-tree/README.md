记忆方法：爸爸和他的兄弟穿橙色球衣，他们的孩子是小队员，叫**堂**；别人家的孩子叫**表**；比我大是哥 / 姐，比我小是弟 / 妹。贯穿三集的是一本"全家福相册"：每叫对一个人，就有一张贴纸飞进去，贴满后的两页就是参考图的样子。

视频本身不设互动停顿，互动在课堂上由老师组织（见教案）。

## 制作方法

画面全部由代码逐帧渲染，不用 AI 视频生成，先出联系表审片再渲染成片。这是本仓库 Opus 5.5 视频案例的做法。

- **故事数据是唯一的数据源。** `video/tools/episodes.py` 写好每个镜头、角色走位、台词气泡、笑点、贴纸和音效的时间，生成 `src/episodes/ep1–3.json`。画面（Remotion）和声音（Python）都读这些文件。
- **人物和场景都是代码画的 SVG。** 16 个角色共用一个人物组件，支持球衣、帽子、变老、举高高、踮脚、跳舞、说话嘴型和手持道具。9 个场景：豆豆家、爷爷家门口、院子、公路、外婆家客厅、量身高门框、照相馆、舞台、相册。
- **声音全部用代码合成。** 每个镜头配一种音乐：拜年的热闹曲、量身高时的音乐盒、儿歌伴奏；音效对准画面上的每个动作；角色说话用"叽里咕噜"的拟声，每人音高不同，老师照气泡读台词；最后统一到 −16 LUFS。

```bash
cd video
npm install
npm run build                 # 故事数据 → 字体子集 → 配乐音效 → 教师讲稿
node tools/stills.mjs ep1 --shots   # 联系表：out/contact.jpg
npm run render                # 三集 MP4：out/
npm run studio                # 在 Remotion Studio 里预览、修改
```

如果没有自动下载的 Chrome，可以把 `REMOTION_BROWSER` 设为本机 Chrome Headless Shell 的路径。字体是霞鹜文楷（SIL OFL 1.1），只打包片中用到的字。
