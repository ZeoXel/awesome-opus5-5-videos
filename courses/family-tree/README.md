# 从"我"出发，找家人 · 幼小衔接动效课

一节 5 分 22 秒的动效教学视频，教 5–6 岁孩子认识家人的称呼：爷爷奶奶、伯伯叔叔姑姑、外公外婆、舅舅姨妈，以及最容易弄混的**堂**和**表**。参考图是《我的家庭图谱》（爸爸这边 / 妈妈这边两页）。

| 文件 | 内容 |
|---|---|
| [`剧本.md`](剧本.md) | 剧本：制作规格、核心视觉想法、角色表、分幕分镜、准确性约束、课堂用法 |
| [`教师讲稿.md`](教师讲稿.md) | 逐句旁白和精确时间码、建议暂停点（由时间轴自动生成） |
| [`video/`](video/) | Remotion 工程：渲染成片、分幕短片、配乐与音效 |

## 这节课怎么教

全片只用一个画面想法：**称谓 = 走一条路 + 比一比。**

- 一个发光小圆点从"我"出发，沿家庭树走到亲戚家。路过爸爸的兄弟（伯伯、叔叔），线变**橙色**，是"堂"；其他路都是**青色**，是"表"。
- 到了孩子身边，两人背靠背量身高：比我大是哥 / 姐，比我小是弟 / 妹。
- 两个字合成一张字卡，拼音写在上面，和课本一致。

| 幕 | 时间 | 内容 |
|---|---|---|
| 0 片头 | 0:00 | 过年来了好多亲戚，该怎么叫？ |
| 1 爸爸这边：长辈 | 0:15 | 爷爷奶奶、伯伯（蛋糕蜡烛多，比爸爸大）、叔叔、姑姑 |
| 2 爸爸这边：孩子 | 1:06 | 堂哥；"我"把姑姑的女儿说成堂妹，再改成表妹；停一停① 堂姐 |
| 3 妈妈这边 | 2:14 | "我"带着连线滑到妈妈这边；外公外婆、舅舅姨妈、表姐表弟；停一停② |
| 4 同一个我 + 儿歌 | 3:29 | 两页合成一张图，中间是同一个我；拍手儿歌（口诀） |
| 5 闯关小测 | 4:10 | 三关：表哥、堂妹、表姐，各有 5 秒倒计时 |
| 6 复习与回家任务 | 5:00 | 六张字卡跟读；回家画家庭树 |

每一幕都能单独导出，方便分课时播放；倒计时处可以暂停，让孩子抢答。

## 制作方法

做法沿用本仓库里 Opus 5.5 视频案例的思路：画面全部由代码逐帧渲染，不用 AI 视频生成，先出联系表审片再渲染成片。

- **时间轴是唯一的数据源。** `video/tools/build_timeline.py` 生成 `src/timeline.json`，里面有每张卡片何时出现、小圆点走哪条路、字卡何时落下、每句字幕和每个音效的时间。画面（Remotion）和声音（Python）都读它，所以音画不会错位。
- **人物是代码画的 SVG。** 16 个角色共用一个 `Figure` 组件，服装颜色取自参考图；会眨眼、呼吸、挥手、举手、点头。
- **声音全部用代码合成。** 音乐盒和木琴配乐，每一幕换风格（讲故事 → 停一停时只剩心跳和嘀嗒声 → 儿歌拍手 → 闯关 → 庆祝）；音效对准画面上的每一次弹出、走路、落字和揭晓；最后统一到 −16 LUFS。
- **审片流程。** 用 `npm run stills` 渲染每幕的关键帧拼成联系表，检查字是否拥挤、线是否穿过人物、颜色是否正确，改完再整片渲染。

### 渲染

```bash
cd video
npm install
npm run build                         # 时间轴 → 字体子集 → 配乐音效 → 教师讲稿
npm run stills                        # 联系表：out/contact.jpg
npm run render                        # 成片 + 6 段分幕：out/
npm run studio                        # 在 Remotion Studio 里预览、修改
```

如果没有自动下载的 Chrome，可以把 `REMOTION_BROWSER` 设为本机 Chrome Headless Shell 的路径。

### 加旁白配音（可选）

制作环境连不上在线语音合成服务，所以成片是"字幕 + 配乐 + 音效"，由老师照讲稿讲。在能联网的电脑上运行：

```bash
pip install edge-tts
python3 tools/tts.py          # 逐句合成到 public/audio/voice/
npm run audio && npm run render   # 自动混入旁白，旁白出现时音乐自动压低
```

倒计时和儿歌部分不配旁白，留给孩子回答和跟读。

### 字体与授权

字体是霞鹜文楷（SIL OFL 1.1），`npm run fonts` 只挑出片中用到的字，放在 `video/public/fonts/`。
