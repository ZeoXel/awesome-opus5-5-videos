# 《豆豆拜年记》幼小衔接教案 · 认识家人的称呼

> 对象：幼升小（5–6 岁）　|　2 课时，每课时 30 分钟　|　配套：动效视频 3 集（2:53 / 2:52 / 1:56）
> 参考图：《我的家庭图谱》（爸爸这边 / 妈妈这边两页）

## 一、为什么这样设计

5–6 岁的孩子不识字，注意力大约 5 分钟一波，靠**故事、动作、儿歌、游戏**学东西，不靠听规则。所以这一版：

| 原来 | 现在 |
|---|---|
| 旁白讲规则，没有情节 | 主角**豆豆**过年去拜年，老叫错人，一路闹笑话一路学会 |
| 家庭关系图、小卡片、大段字幕 | 大场景：爷爷家、外婆家、照相馆；人物大、有性格 |
| "走哪条路"判断堂 / 表（大人的逻辑） | **兄弟足球队**：爸爸和他的兄弟穿橙色球衣，他们的孩子是小队员，叫"**堂**"；其他人家的孩子穿青色，叫"**表**" |
| 用身高比较 | 在门框上**量身高**，表妹还会偷偷踮脚 |
| 只有"大声说出来" | 每 30 秒一个互动：帮豆豆喊、做动作、唱儿歌、抢答 |
| 学完就结束 | 叫对一次就得一张**全家福贴纸**，贴满相册，最后一起拍全家福 |

## 二、教学目标

1. **会叫**：能说出爷爷、奶奶、伯伯、叔叔、姑姑、外公、外婆、舅舅、姨妈。
2. **会分**：知道爸爸的兄弟家的孩子叫"堂"，姑姑、舅舅、姨妈家的孩子叫"表"。
3. **会比**：比我大的叫哥哥、姐姐，比我小的叫弟弟、妹妹。
4. **会用**：过年见到亲戚，愿意主动、有礼貌地打招呼。
5. **认读**（拓展）：认读"堂、表、哥、姐、弟、妹"，跟读拼音。

**重点**：长辈的称呼，哥姐弟妹。**难点**：分清堂和表。达不到目标 2 的孩子不强求，认识长辈、会比大小就算达标。

## 三、四个"魔法口令"（全课反复用）

| 口令 | 动作 | 用在哪里 |
|---|---|---|
| **比我大** | 双手举高高，踮脚 | 哥哥、姐姐 |
| **比我小** | 蹲下，手放低 | 弟弟、妹妹 |
| **堂** | 双手拍拍胸口（拍球衣） | 伯伯、叔叔家的孩子 |
| **表** | 双手在头顶挥一挥 | 姑姑、舅舅、姨妈家的孩子 |

孩子边说边做，比如"堂哥"就是先拍胸口，再举高高。视频本身不停顿，口令动作由老师在课堂上带着做。

## 四、准备

- 视频第 1–3 集（教室大屏，带声音）。
- 3 件橙色号码背心（1、2、3 号），2 件青色背心，一个小足球（游戏用）。
- 门框身高墙：在门边贴一条彩色刻度纸。
- 学习单《我的全家福相册》（左页爸爸这边、右页妈妈这边，和参考图一样），每人一份；人物贴纸一套。
- "小帮手"奖章贴纸。

## 五、第 1 课时：去爷爷家拜年（爸爸这边）

| 时间 | 环节 | 怎么做 |
|---|---|---|
| 3 分钟 | 导入：猜猜他是谁 | 老师出示自己的家庭照片（或卡通图），请孩子猜"这是老师的谁"。引出："过年要拜年，叫错了可就闹笑话啦！" |
| 4 分钟 | 看第 1 集上半段（0:00–1:31） | 认识爷爷、奶奶、爸爸和兄弟足球队、姑姑。可在 **1:08**（叔叔被叫成"爷爷"变老）按暂停，问"豆豆叫错了，应该叫什么？" |
| 7 分钟 | **游戏：兄弟足球队站一站** | 请 3 个孩子穿 1、2、3 号橙色背心，扮演伯伯、爸爸、叔叔，按号码排队。全班一起喊："1 号比爸爸大——伯伯！3 号比爸爸小——叔叔！"再请一个女孩来当姑姑："姑姑能进兄弟队吗？""不能！她是爸爸的妹妹。" |
| 4 分钟 | 看第 1 集下半段（1:31–2:53） | 堂哥、表妹。可在 **2:02**（豆豆说她是"堂妹"）按暂停，先让孩子猜"她该穿什么颜色？" |
| 7 分钟 | **游戏：门框量身高** | 两个孩子背靠背站在身高墙前，全班判断并做动作："比我大，举高高——哥哥！"然后加上球衣："他穿橙色背心，拍拍胸口——堂哥！" 轮换 3–4 组。 |
| 3 分钟 | 贴相册 | 在学习单左页贴上爸爸这边的 8 张贴纸。领"小帮手"奖章。 |
| 2 分钟 | 回家任务 | "回家问问爸爸：你有没有哥哥、弟弟、姐姐、妹妹？" |

## 六、第 2 课时：去外婆家拜年 + 拍全家福

| 时间 | 环节 | 怎么做 |
|---|---|---|
| 3 分钟 | 复习：魔法口令 | 老师喊称呼，孩子做动作：堂哥（拍胸口 + 举高）、表妹（挥手 + 蹲下）……越来越快。 |
| 6 分钟 | 看第 2 集 | 开头是上集回顾。可在 **1:15**（叔叔探头抢球衣）按暂停："舅舅是谁的兄弟？"——"妈妈的！" |
| 5 分钟 | **游戏：妈妈这边没有兄弟队** | 发青色背心给"表姐、表弟"，老师问："妈妈这边的孩子，能穿橙色吗？""不能，都叫表！" |
| 5 分钟 | 看第 3 集：全家福 + 儿歌（0:00–1:17） | 起立，跟视频拍手唱《两只老虎》调的家人歌，可以拖回 0:36 重复唱。 |
| 5 分钟 | 看第 3 集结尾 + **课堂闯关** | 视频里复习六张字卡。之后老师出题（如"姑姑家的男孩，比我大"），分组抢答，答对的组得一颗星。 |
| 4 分钟 | 贴相册 + 合页 | 贴好妈妈这边，把相册合起来："两页中间，是同一个我！"请几个孩子介绍自己的相册。 |
| 2 分钟 | 家园共育 | 发《拜年小任务》：过年时主动叫对 3 位亲戚，请家长拍照或打勾。 |

## 七、儿歌（《两只老虎》调，传统曲调）

> **第一段**
> 伯伯叔叔，伯伯叔叔，家的娃，叫"堂"呀；
> 姑姑舅舅姨妈，他们家的娃娃，都叫"表"，都叫"表"。
>
> **第二段**
> 比我大的，比我大的，是哥哥，是姐姐；
> 比我小的弟弟，比我小的妹妹，拉拉手，拉拉手。

唱到"堂"拍胸口，"表"挥手，"比我大"举高高，"比我小"蹲下，"拉拉手"和同桌拉手。

| 孩子 | 会叫 5 位长辈 | 会比大小 | 分得清堂 / 表 | 愿意主动打招呼 |
|---|---|---|---|---|
| | ☐ | ☐ | ☐（拓展） | ☐ |

## 九、给老师的提示

- **兄弟足球队只是帮助记忆的比喻。**真正的规则是：爸爸的兄弟（伯伯、叔叔）的孩子叫"堂"，其余的都叫"表"。**不要用"跟我一个姓"来讲**，有的孩子随妈妈姓，会被弄糊涂。
- 有的孩子家里没有某位亲戚，或者是单亲、重组家庭。讲的时候说"有的小朋友家里有……"，相册里允许空着，也可以贴上自己真正的家人。
- 外公 / 外婆在北方常叫姥爷 / 姥姥，姨妈也叫小姨、阿姨。可以告诉孩子"两种叫法都对"，并请孩子说说自己家怎么叫。
- 伯伯和叔叔有的地方都叫"大爷""叔"，同样可以说明。
