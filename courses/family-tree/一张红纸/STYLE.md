# STYLE · 一张红纸（剪纸风）

## 1. 是什么
春节窗花式的剪纸动画。所有人物、文字、连线都是"剪出来的纸"，平铺在宣纸上，带一层抬起的投影；五官和花纹是真正的镂空，逆光时会透出光。

## 2. 适合讲的故事
关系、结构、成对的东西：家谱、分类、对称、"从一处展开"的知识。不适合写实场景或复杂动作。

## 3. 视觉语言
| 项 | 值 |
|---|---|
| 底 | 宣纸 #F4ECDD，叠 25% 分形噪声纸纹，加 140 根浅色纤维（#C9B898，35%） |
| 主纸 | 正红 #C8102E；折叠层、背面用 #9E0B22 / #7E0A1C |
| 堂 | 金纸 #E3A73A（文字强调色 #B07A1A） |
| 表 | 青纸 #2E9AA8 |
| 墨 | #2A211C，用于名字签和字幕 |
| 桌面 | 木色 #A9764A，带木纹曲线 |
| 逆光 | 纸变 #7E1414，背后径向暖光 #FFE3A0 → #F6A65A → #3B2350 |
| 投影 | 偏移 (7, 9)，模糊 5，#3A1A10 32% |
| 字体 | 霞鹜文楷 Bold；剪出来的字用纸色并带投影（CutText） |

**造型规则（PaperFigure）：**
- 一个人只有一张实心剪影，靠轮廓区分：头发 / 帽子 / 胡子 / 拐杖 / 手持物。
- 每个亲戚必须有一个独有的轮廓特征：

| 人物 | 独有特征 |
|---|---|
| 爷爷 | 秃顶两侧鬓发、眼镜、拐杖 |
| 奶奶 | 发髻、头花 |
| 伯伯 | 侧分、八字胡、最高最壮 |
| 爸爸 | 短发（基准） |
| 叔叔 | 鸭舌帽 |
| 姑姑 | 麻花辫、袄裙 |
| 外公 | 瓜皮帽、长须 |
| 外婆 | 小卷发 |
| 妈妈 | 长直发、袄裙 |
| 舅舅 | 短发、宽身 |
| 姨妈 | 丸子头、耳坠、袄裙 |
| 我 | 绒球帽 |
| 堂哥 | 抱足球（镂空五边形） |
| 表妹 | 双髻 |
| 表姐 | 马尾 |
| 表弟 | 冲天辫 |

- 服装三种轮廓：长袍（祖辈）、短袄加裤（男、男孩）、袄裙（女、女孩）。
- 镂空固定一套：月牙眼、月牙笑、两个腮红小圆、发际线细缝、领口弧线、三颗菱形扣、锯齿纹衣摆；裙子加三片叶形纹。
- 头身比放大（成人头半径 41，孩子 36 + 身高×0.04），保证缩小后脸仍可读。
- 兄弟姐妹之间用"手拉手"的纸娃娃串相连，不画额外连线；隔代、亲子之间用纸条连线，纸条颜色即知识点（红 / 金 / 青）。

## 4. 运动语言
- **剪：** 剪刀沿虚线走，纸屑三角掉落，被剪下的部分抬起 6px，投影随之变大。
- **展开：** 纸娃娃串像手风琴一样逐片拉开；成对的人（爷爷奶奶）由一张对折的小纸展开。
- **贴：** 纸片落下时轻微回弹（不超过 3%），落定后投影收紧。
- **翻页 / 折痕：** 转场在纸里完成，翻页或沿折痕合上再打开，不用硬切。
- **线条：** 不做抖动（剪纸边缘应该是利落的），只在"正在剪"时让剪刀走过的边有 1px 毛边。
- **缓动：** 落纸用 easeOutBack（小过冲），拉开用 easeInOut，合页用慢入慢出加 0.2 秒停顿。

## 5. 镜头表
| 镜头 | 用途 |
|---|---|
| 俯拍桌面（固定 / 慢推） | 剪、展开 |
| 横移跟随纸娃娃串 | 兄弟姐妹一排 |
| 推近到单人 | 堂哥、表妹等特写，主体占画面高度 ≥ 1/3 |
| 翻页 | 爸爸这边 → 妈妈这边 |
| 招牌镜头：桌面摇到窗户 | 剪纸贴上窗变成窗花，逆光 |
| 收尾拉远 | 整扇窗 |

## 6. 声音配方
- 每一刀一个剪刀声（短噪声加金属高频），纸屑落下有沙沙声。
- 展开纸娃娃串用"刷啦"纸声，每个名字落定配一声古琴或琵琶拨弦（Karplus–Strong 合成），音高按辈分从低到高。
- 配乐：拨弦加木鱼，轻；至少两处真静音（S4 前 1.5 秒、S6 前 2 秒）。
- 配音：老师问、孩子答，两种音色（index-tts-v2 克隆，参考音固定）；下一句提前 0.4 秒进入（J-cut）。
- 母带：−14 LUFS，True Peak −1.2 dB。

## 7. 字幕
- 底部一条米白纸签，左边圆章写"问"（墨色）或"答"（红色），台词 50px。
- 停留时长 ≥ 字数 ÷ 4.5 + 1.5 秒，且 ≥ 配音时长 + 0.6 秒。
- 名字签：纸签加墨字，堂 / 表的第一个字用金色或青色。

## 8. 踩过的坑
- 尖刺头发在剪纸里像皇冠，已换成短发加足球。
- 全身统一长袍时，人物只能靠头部区分，缩小后认不出，所以必须分三种服装轮廓。
- 折叠中的纸娃娃若用 scaleX 压扁，看起来像"更小的人"；改用错位叠放的纸层（加深一档颜色）。
- 名字签会挡住通往孩子的纸条，而纸条颜色正是"堂 / 表"的知识点；排版时行距要留出 ≥ 40px 的可见纸条。
- 窗格横档不能压在人物脚上。
- mask 的 id 在同一帧内必须唯一（`pm-${id}`），否则人物会互相"借"镂空。

## 9. 制作命令
```bash
cd courses/family-tree/video
node tools/paper_stills.mjs      # 4 张风格关键帧 → out/paper-kf-*.png
```

## 10. 引擎 API
- `PaperFigure({who, id, color, arms: 'down' | 'out', reach, backlit})`：剪纸人物，原点在两脚之间。
- `geometry(who)`：返回头半径、肩线等，用于摆放纸条和手拉手。
- `PaperDefs`：纸纹、投影、辉光的 defs，每帧渲染一次。
- `RicePaper` / `Table`：背景。
- `Strip`：纸条连线。
- `Tag`：名字签。
- `CutText`：剪纸字。
- `Scissors`：剪刀。
- `Line`：问答字幕条。
